# Tique 1.1.2 — Android icon and bilingual documentation

[Português](../../releases/v1.1.2.md)

The Android icon now uses the same gold geometric symbol as the header, on black. It includes a standard image, adaptive layers, and a monochrome version for themed icons. Configuration follows the [Expo documentation](https://docs.expo.dev/develop/user-interface/splash-screen-and-app-icon/). SVGs and PNGs are original project assets, with no new APK dependency.

Repository documentation is available in Portuguese and English, with language navigation, contributing guides, and bilingual bug/feature forms. Checkboxes follow the careful-reading structure of [end-4](https://github.com/end-4/dots-hyprland/blob/main/.github/ISSUE_TEMPLATE/1-issue.yml), with original content: required reading and privacy checks, optional updating and “checked without reading” checks, and no automatic issue closing. Do not upload real financial data.

Update over the existing installation. Version 1.1.2/code18 preserves package, signature, and data. The app interface remains Portuguese; this release translates documentation rather than localizing screens.
