# FFortuna v0.4.0-alpha.1 — automatic recovery and synthetic security

Experimental Android prerelease, using fictional data only. Internal version 0.4.0 (versionCode 4), package `org.ffortuna.capturepoc`, arm64-v8a, Android 8/API 26 or later. It does not capture Nubank or accept real financial data.

The app automatically creates up to three local encrypted copies of records/parsing, without raw data, at most one every 24 hours and only when changes exist. Interface restoration and password-protected portable backup are in Advanced settings. Internal copies depend on the installation and do not survive uninstall; portable backup saved outside the app is independent of the local key.

30-day raw-data retention now also covers the previous vault without activating it; it preserves records/parsing and shows a block if the key is unavailable. Missing or invalid databases fail rather than silently recreating the vault. The security battery uses only isolated synthetic vaults/keys and pauses capture.

## Install and validate

Download `ffortuna-capture-poc-arm64.apk` from the attachments and open it on the phone. Install over 0.3.0 without uninstalling: package and signing certificate are unchanged. Metro, EAS, an Expo account, and INTERNET are not required.

Check the local recovery policy. In **Advanced settings**, list/restore a copy and run **Run isolated native checks**. Report the passed/failed/not-verified counters and any IDs/codes needing attention. Full procedure: [captura-nativa.md](https://github.com/richardheise/Tique/blob/v0.4.0-alpha.1/docs/captura-nativa.md#recuperação-automática-e-segurança--roteiro-040).
