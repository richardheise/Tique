# Tique v0.6.1-alpha.1 — new name, same installation

The app and repository changed from FFortuna to **Tique**, named after the Greek goddess of fortune. The repository is now [richardheise/Tique](https://github.com/richardheise/Tique).

This prerelease includes the 0.6.0 BRL preview increment and applies the new name to the splash screen, permissions, fictitious notifications, licenses, Expo Go demo, and new export files. The APK is named `tique-arm64.apk`; internal version is 0.6.1 (versionCode 7), arm64-v8a/Android 8+.

## Compatibility

**Install over the existing app, without uninstalling.** Package remains `org.ffortuna.capturepoc` and signing certificate is unchanged. Databases, Keystore aliases, consents, native module, and backup formats/extensions keep legacy identifiers to preserve existing data/files. Previous tags and attachments remain intact. Local working directory and legacy environment variables were also retained; they do not appear as branding in the main interface.

The BRL increment looks for real values in the original and creates reviewable previews. Reprocessing preserves saved corrections; the export copy remains masked with R$ 12,34. There are no validated bank templates, automatic posting, real balance, or financial ledger. **Previews and corrections are still temporary diagnostic data and expire after 7 days with the observation.**

## Test

1. Install `tique-arm64.apk` from the attachments over the previous version. Check the Tique name and that existing records still within retention are present.
2. In Advanced settings, run the **48 isolated native checks** before starting another capture session.
3. Tap **Interpret original**, check the real value and evidence snippet, correct fields, and save. Reprocess and reopen: the review should remain, without a duplicate candidate.

[Full BRL increment procedure](https://github.com/richardheise/Tique/blob/v0.6.1-alpha.1/docs/previa-brl.md). Report only counters/codes and results, without originals, personal values, or passwords in this conversation.

## Validation

Strict TypeScript and 30 TypeScript tests passed. 50 JVM tests passed and 46 Android scenarios compiled. Visible Tique name, legacy package, and unchanged certificate were checked in the final APK; Android backup disabled, offline bundle, restricted permissions, notices, and 23 libraries aligned to 16 KB passed inspection. Interface battery adds sandbox cleanup and own-log window, totaling 48. Android JUnit runner was not run on this server; **physical validation of 0.6.1 is pending**. Previous functional approval refers to 0.5.0.

No dependency or permission was added for the name change. Build preserves the 12 GiB/16 CPU ceiling; APK is release with offline bundle, no INTERNET, Expo account, or EAS. Third-party notices and copyrights were preserved; only the original preface with branding/URL changed.
