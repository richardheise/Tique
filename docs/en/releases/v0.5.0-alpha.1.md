# FFortuna v0.5.0-alpha.1 — optional local diagnostics

Experimental Android prerelease: internal version 0.5.0 (versionCode 5), package `org.ffortuna.capturepoc`, arm64-v8a, Android 8/API 26+. Demonstrations and examples remain synthetic. This version adds optional, temporary diagnostics for real notifications, without parsing or bank postings.

## What changed

- On-device check of the installed Nubank package, version, and observed signature. Query is restricted to `com.nu.production`, without listing all apps. The local signature is not presented as an official certificate.
- Collection is initially disabled. Starting requires **40 synthetic checks passed** in this version/process and explicit consent. Sessions last up to 24 hours and are limited to 200 observations in the same Android profile; device restart requires new consent.
- Separate SQLCipher/Keystore vault, without JavaScript, financial logs, plaintext temporary files, or integration with synthetic backups. Originals/revisions expire after seven days when the core runs.
- Identity/revisions distinguish redelivery, update, and identical notifications with their own keys. Group summaries retain metadata only; there is no transaction or balance change.
- Assisted review is required before export. Up to 20 reviews, with suggestions for identifiers and amounts; names/places/free text need manual checking. Anonymization is not guaranteed.
- Optional password-encrypted export of confirmed fields only, without originals, real IDs, times, signature, groups, or device. “Check exported file” authenticates/validates in memory and does not import records. Files are not shared or sent.
- `FLAG_SECURE` is set for the APK window; interface text/passwords are cleared when moving to background. Complete removal of internal memory copies or control over keyboards is not promised.

## Install and test

Download `ffortuna-capture-poc-arm64.apk` from the attachments and install over 0.4.0 without uninstalling. Package and signature are unchanged. The APK does not require Metro, EAS, an Expo account, or INTERNET.

1. In Advanced settings, run **Run isolated native checks**. Expected: 40 passed, zero failures, zero not verified. Real collection remains blocked until they pass.
2. Check the installed source and only then consent to the temporary session. Wait for a legitimate notification during normal Nubank use; a bank transaction is not required to test.
3. Refresh diagnostics, review a sample, and confirm removal of names/merchants/personal data. Export with a password to a local folder and check the file with a wrong/correct password. Stop collection when done.

[Full policy and procedure](https://github.com/richardheise/Tique/blob/v0.5.0-alpha.1/docs/diagnostico-local.md). Report counters/codes and functional results only; do not send originals, passwords, or financial data in this conversation. The encrypted file is not a ready-made Git fixture.
