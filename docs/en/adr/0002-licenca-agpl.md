# AGPLv3 license

The user chose the AGPL for the new app; GNU AGPL version 3 (`AGPL-3.0-only`) will be used. The alternatives discussed were GPLv3 and permissive licensing; this choice records a preference for copyleft that also covers network interaction scenarios addressed by the license.

Consequences: include the complete license text and comply with its requirements in applicable distributions and uses. This choice does not authorize copying code, assets, or marks from references: component compatibility, notices, and terms must be checked before any reuse.
